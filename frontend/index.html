Atur

      Query parameter otomatis ditambahkan ke URL saat kirim request.

      Gunakan :nama atau {{nama}} di URL, lalu isi nilainya di sini.

      Menambahkan header: Authorization: Bearer <token>

      Menambahkan header: Authorization: Basic <base64(user:pass)>

      Menambahkan header kustom dengan nama dan nilai yang ditentukan.

      Kirim request untuk melihat response di sini.
